# zemax-learning-journal

Project files (`.zos`), spec sheets, and images from my Zemax OpticStudio learning journey. Write-ups with full context live on the [companion blog](#) — this repo is the archive of the actual work.

## Structure

```
01_ray_optics/         Weeks 1-3: sequential ray tracing fundamentals
02_system_design/       Weeks 4-6: optimization, tolerancing
03_source_coupling/     Weeks 7-8: laser/fiber/LED coupling
04_illumination/        Weeks 9-11: Non-Sequential illumination optics
05_capstone/            Weeks 13-16: full PL microscopy system design
```

Each project gets its own subfolder inside the relevant phase folder, containing:
- `[project-name].zos` — the Zemax file itself
- `README.md` — 2-3 sentence summary + link to the full blog write-up
- `images/` — layout screenshots, spot diagrams, analysis plots referenced in the write-up
